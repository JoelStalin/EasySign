# Contributing to EasySign

Use TypeScript strict mode, small cohesive modules, dependency inversion and explicit error handling. Prefer readable domain names, avoid premature abstraction, keep transport logic out of domain logic. No secrets or biometric test data in Git.

Branch: feat/ES-###-short-description. PR must reference issue, tests, threat impact, screenshots if UI, migration/rollback notes and acceptance evidence. Require review, passing CI and security gates before merge. Never treat a passing unit test as a pentest.

See docs/SCRUM_DELIVERY.md, docs/SECURITY_TESTING.md and docs/SPRINT_BACKLOG.md.
